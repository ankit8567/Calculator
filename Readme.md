# 🧮 Fancy Calculator

> **A modern, responsive, and interactive calculator built using HTML, CSS, and JavaScript.**

---

## ✨ About The Project

**Fancy Calculator** is a stylish web-based calculator designed with a modern **glassmorphism UI** and smooth interactive animations.

The calculator performs basic mathematical operations while providing a clean and responsive interface that works on **desktop, tablet, and mobile devices**.

It also supports **keyboard input**, making calculations faster and more convenient.

---

## 🌟 Features

| Feature                | Description                                |
| ---------------------- | ------------------------------------------ |
| ➕ Addition             | Performs addition operations               |
| ➖ Subtraction          | Performs subtraction operations            |
| ✖️ Multiplication      | Performs multiplication operations         |
| ➗ Division             | Performs division operations               |
| % Percentage           | Supports percentage calculations           |
| 🧹 Clear               | Clears the complete calculation            |
| ⌫ Delete               | Removes the last entered character         |
| ⌨️ Keyboard Support    | Perform calculations using your keyboard   |
| 📜 Calculation History | Displays the previous expression           |
| ✨ Animations           | Interactive button hover and click effects |
| 📱 Responsive Design   | Works on different screen sizes            |
| 🪟 Glassmorphism UI    | Modern transparent glass-style interface   |

# 🚀 How To Run

## 1️⃣ Open the Project

Open the `Calculator` folder in **Visual Studio Code**.

## 2️⃣ Check Your Files

Make sure the folder contains:

```text
Calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 3️⃣ Run Using Live Server

Install the **Live Server** extension in VS Code.

Then:

```text
Right Click index.html
        ↓
Open with Live Server
```

The calculator will open automatically in your browser.

### Alternative

Simply double-click:

```text
index.html
```

and it will open in your default browser.

# 🧮 How To Use

### 🔢 Enter Numbers

Click any number button:

```text
1  2  3
4  5  6
7  8  9
```

### ➕ Perform Calculations

Example:

```text
25 + 15
```

Press:

```text
=
```

Result:

```text
40
```

### ⌫ Delete

Use the **⌫** button to remove the last character.

### 🧹 Clear

Press **AC** to reset the calculator.

### ⌨️ Keyboard Controls

| Key         | Function       |
| ----------- | -------------- |
| `0–9`       | Enter numbers  |
| `+`         | Addition       |
| `-`         | Subtraction    |
| `*`         | Multiplication |
| `/`         | Division       |
| `%`         | Percentage     |
| `.`         | Decimal        |
| `Enter`     | Calculate      |
| `Backspace` | Delete         |
| `Esc`       | Clear          |
